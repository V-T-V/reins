go-rmm 部署指南（零配置版）
============================

【部署架构】
  Linux 服务器：go-rmm-relay（内嵌 Web UI + API + WS 中继，单文件）
  Windows 被控机：go-rmm-agent（反向连接 Relay，服务化）

【零配置部署（2 行命令）】

① Linux 服务端（无需任何参数）：
   ./go-rmm-relay-linux
   → 自动启动 :7780，Web UI 内嵌，无 token 校验

② Windows 被控端（管理员 PowerShell，只填 IP）：
   .\go-rmm-agent.exe install -relay 服务器IP
   → 自动补全为 ws://IP:7780/agent
   → 自动安装为服务 + 启动 + 连接

③ 浏览器打开：
   http://服务器IP:7780
   → 首次打开显示安装引导（含可复制的命令）
   → Agent 上线后自动进入控制台

【可选：token 鉴权（公网部署建议）】

   ./go-rmm-relay-linux -token 你的密钥
   .\go-rmm-agent.exe install -relay 服务器IP -token 你的密钥

【可选：systemd 开机自启（Linux）】

   cat > /etc/systemd/system/go-rmm-relay.service << 'EOF'
   [Unit]
   Description=go-rmm Relay
   After=network.target
   [Service]
   ExecStart=/opt/go-rmm-relay-linux
   Restart=always
   [Install]
   WantedBy=multi-user.target
   EOF
   systemctl enable --now go-rmm-relay

【Agent 管理】
   install   注册为 Windows 服务
   start     启动
   stop      停止
   status    状态
   uninstall 卸载
   run       前台调试

【-relay 参数支持的格式】
   192.168.1.100         → 自动补全 ws://192.168.1.100:7780/agent
   192.168.1.100:9999    → ws://192.168.1.100:9999/agent
   relay.example.com     → ws://relay.example.com:7780/agent
   ws://host:7780/agent  → 原样使用
